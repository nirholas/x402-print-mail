x402 · pay per call

x402-print-mail

Physical letters and postcards sent through Lob — give it an address and a paragraph, get back the proof PDF and the expected delivery date. Every paid route answers an unpaid request with 402, then returns the purchased artifact in the body of the same request once you retry with an X-PAYMENT header.

Pay for one call

curl -s -X POST "$BASE/letters" -H 'content-type: application/json' \
  -d '{"to":{"name":"Ada Lovelace","line1":"1 Main St","city":"Denver","state":"CO","zip":"80202"},"body":"Hello from an agent."}'
# 402 + accepts[] — retry with an X-PAYMENT header, or let x402-fetch do it

The 402 challenge carries the call schema for the route it guards (accepts[].outputSchema.input / .output), so an agent that has never read this page can still invoke the endpoint correctly.

Payment

  • USDC on Base (EIP-3009) or Solana (SPL transfer, facilitator-sponsored fees) — your wallet picks the rail.
  • Charged per request. No account, no API key, no subscription.
  • Settlement receipt returns in the X-PAYMENT-RESPONSE header and in the response body.
